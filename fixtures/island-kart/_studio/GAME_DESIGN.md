# 椰风海岛 · 游戏合同

面向非专业玩家，首次打开直接展示玩法与操作。核心是连续转向、选择收集路线、判断冲刺时机，不是固定道闪避。

## 操作

- 自动前进；左右方向键 / A、D 或触屏按钮转向。
- 空格或触屏冲刺键消耗 40 能量，加速 2.1 秒。
- 下方向键 / S 可选减速；P / Esc 或暂停键暂停。
- 开局可选新手转向辅助。声音默认关闭，音符键开启。

## 规则与反馈

- 三车同场（玩家 + 两个 AI），共用最高速度、碰撞与道具处理。
- 三圈赛必须完成三个完整赛道距离才结算；自由驾驶无限圈，不结算胜负。
- 金币只奖励收集者并补充能量；道具箱自动给护盾或能量，无额外操作菜单。
- 碰撞减速但不死亡；暂停不推进任何规则，失焦自动暂停并清空输入。
- 计时、名次、圈数、能量、速度、金币与小地图持续反馈。
- 冲线演出后出现领奖台、最快单圈、总时间与个人纪录；只写入 island-kart.records.v1，辅助/标准纪录分开保存。
