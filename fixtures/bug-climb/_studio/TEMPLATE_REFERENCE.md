# 核心玩法模板：Subway Surfers

## 选择结论

本游戏的唯一核心玩法模板锁定为 **Subway Surfers（地铁跑酷）**。原因不是题材相似，而是它已经验证了竖屏三车道闪避的关键合同：玩家固定在画面下方、三条路线始终可判断、障碍提前进入视野、横向输入立即完成、速度提高但不牺牲公平性。

参考来源：

- Apple App Store 产品页：https://apps.apple.com/us/app/subway-surfers/id512939461
- Apple 编辑推荐分析：https://apps.apple.com/us/iphone/story/id1453245869
- 当前 App Store 游戏画面归档：https://appscreens.store/app/subway-surfers

只借鉴玩法比例、镜头组织和反馈节奏；不复制角色、列车、场景、商标、配色或其他美术资产。

## Refero 研究与视觉边界

- 主视觉风格继续锁定 Gt-planar（`8ac461ad-1f30-4829-bb6e-dc68f1d2b6dd`）：黑色沉浸画布、径向速度线、紧凑技术 HUD、极少量高亮信号色。
- Ferrari（`306ff7bc-d98d-478f-84ef-d7e99d5d119a`）只负责赛车语义和红色危险信号。
- Project Indigo（`36ee917b-a8f7-407d-a8d8-4caf126c9cf2`）只负责全屏视野与贴边控制结构。
- Subway Surfers 只负责玩法模板，不改变现有霓虹赛车的独立美术方向。

## 参考锁定

**必须保留：** 玩家载具稳定锚定在画面下方；载具明显窄于单车道；远端长期可见；障碍从小到大连续接近；输入后快速完成换道；画面中央保持清楚，速度感集中在道路纹理与周边视野。

**拒绝：** 用大车体制造“力量感”；用数字时速代替真实运动；全屏泛光遮挡障碍；高速时缩短到不可反应；复制 Subway Surfers 的角色、美术或品牌元素。

**量化目标：**

- 390×844 竖屏下，车体视觉宽度不超过所在车道宽度的 75%。
- 车体视觉高度约占赛场高度 10%–13%，底部锚点稳定。
- 标准巡航速度比上一版提高约 40%，但障碍生成间隔按时间重新平衡。
- 路面光流速度为真实前进速度的 1.75 倍；氮气时提升到约 2.4 倍以上。
- 换道追随速度提高约 70%，碰撞判定宽度略微收紧，避免视觉上已经躲开却仍受击。
- 手机端仍保持 60px 主触控高度、0 页面溢出和完整状态循环。

## 决策记录

| 决策 | 来源 | 采用规则 | 目的 |
| --- | --- | --- | --- |
| 锁定一个模板 | 用户要求 | Subway Surfers 作为唯一玩法模板 | 避免继续混合多个游戏导致规则失焦 |
| 缩窄赛车 | Subway Surfers 游戏画面 | 玩家轮廓显著窄于路线净空 | 邻道障碍与赛车之间出现可读空隙 |
| 保持长距离预读 | Apple 编辑推荐 | 换道与障碍判断不能依赖猜测 | 高速同时保持公平 |
| 加快真实推进 | Subway Surfers 三车道循环 | 难度通过速度递增，输入仍即时 | 让障碍接近速度可被身体感知 |
| 独立强化光流 | Gt-planar | 径向运动集中在周边 | 强化速度但不遮挡中央危险物 |
| 缩短换道追随 | Apple 编辑推荐 | 操作紧、响应明确 | 视觉位置与碰撞位置更快一致 |
| 不复制美术 | 版权与产品边界 | 仅复用玩法合同 | 保留霓虹极轨的独立身份 |
