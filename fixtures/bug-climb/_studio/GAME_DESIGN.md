# 虫虫攀枝 · 游戏设计文档

## 产品定位

- 类型：Q 版森林正交顶视图三路线高速闪避
- 单局时长：约 3–5 分钟
- 玩家幻想：化身小瓢虫沿巨树表面向上疾爬，在树皮纹理不断下掠时贴边闪避并积蓄露珠能量。
- 核心爽点：路线预判、险避连击、冲刺速度断层、破障释放，以及树皮从脚下快速后退的直接速度感。

## 核心循环

1. 从正交顶视图观察三条等宽树纹上的障碍与收集物。
2. 使用上下左右键、触控按钮或四向滑动调整位置。
3. 用瓢虫头部碰到露珠使其爆开并吸收能量，贴近树瘤险避并提高连续倍率。
4. 按住露珠冲刺，让树皮滚动速度跃升并撞碎琥珀树脂。
5. 在倒计时结束前通过 3 个树层，抵达树冠。

## 规则

- 普通树瘤必须绕开；碰撞会损失 1 点体力并清空连续倍率。
- 琥珀树脂只能在露珠冲刺时撞碎，否则按普通碰撞处理。
- 露珠只要与瓢虫头部相触就立即爆开消失并提供冲刺能量；金色种子提供额外分数和永久收集进度。
- 每个树层都会提高基础速度并缩短障碍间隔，但仍保证至少一条可达路线。
- 体力降到 0 或倒计时结束时失败；完成第 3 层后获胜。

## 镜头与速度合同

- 镜头必须垂直朝向树皮，三条路线从画面顶部到底部保持等宽、平行。
- 瓢虫默认位于画面下半部，可在安全范围内上下移动；镜头仍保持固定，纵向移动不会改变路线宽度。
- 主角位图只保留触角、头部和甲壳，不含固定腿；六条动态腿分别从胸部前、中、后三组关节伸出，前足向前、中足向侧、后足向后，左右脚交替迈步，静止时停止摆动。
- 树皮主背景、苔藓缝和边缘叶片必须随推进量整体向下平移，不得只移动障碍。
- 障碍和收集物使用固定视觉尺寸，不进行远小近大缩放。
- 冲刺同时提高树皮下掠速度、垂直光流、速度读数、环境音高和触觉反馈。

## 视觉与移动端约束

- 4:3 桌面画布与手机竖屏共用正交顶视图和三条固定路线。
- 角色宽度必须小于单条路线宽度，手机端额外缩小，保留完整换道净空。
- 五枚触控按钮位于画面下方，提供左、上、冲刺、下、右，游玩时不遮挡障碍落点。
- 核心角色、背景、收集物和障碍均使用 AI 生成的 PNG 位图；禁用 SVG、Emoji 和字符代替主美术。
- 高对比、色觉辅助和柔和动效可在开始页切换。

## 验收重点

- idle、playing、won、lost 与重新开始状态完整可达。
- 360×640、390×844、1366×900 均无横向溢出且开始按钮首屏可见。
- 任意游玩帧中，三条路线保持等宽；角色和同类障碍的尺寸不因纵向位置改变。
- 连续帧可测得树皮向下位移，角色纵向位置保持稳定。
- 浏览器运行期间无未处理异常或控制台错误。
