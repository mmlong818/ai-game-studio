# 虫虫攀枝 · 移动端体验

## 目标

手机端必须在单屏内同时提供完整四向移动和冲刺，按钮不能遮挡游戏路线，玩家也可以直接在树皮上四向滑动。开始、游玩、胜负和重开均不得引发页面滚动或横向溢出。

## 操作布局

- 底部操作区按“左、上、冲刺、下、右”排列，方向与角色运动一致。
- 390px 宽度下四枚方向键均为 52×58px，冲刺键为 156×58px。
- 320px 宽度下方向按钮只显示箭头，仍保持至少 46px 宽、54px 高。
- 画布滑动时，纵向位移大于 28px 且超过横向位移即触发上爬或下爬；否则处理左右换道。
- 键盘方向键与 WASD 对应同一套四向移动逻辑，空格保持冲刺。

## 画面与判定

- 三条路线从上到下等宽，角色上下移动不会改变占道比例。
- 角色默认位于下半部，可在画布内部 430–590 范围移动，始终避开顶部 HUD 和底部进度条。
- 露珠使用头部接触判定，接触后立即隐藏并播放水花爆裂；不会继续跟随场景穿过身体。
- 障碍、露珠和种子不绘制额外阴影底图，减少手机小尺寸下的重叠噪声。

## 已验证

- 390×844：上移后角色纵坐标由 540 降至 486，下移后恢复到 539。
- 390×844：头部拾取测试使露珠能量从 0 增加到 25，露珠存活数变为 0，并产生 20 枚水花粒子。
- 方向按钮实测 52×58px，冲刺按钮 156×58px。
- 360×640、390×844、1366×900 均无横向溢出；完整状态循环无浏览器错误。
