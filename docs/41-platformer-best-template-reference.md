# 《云脊跃迁》最佳模板参照与重构合同

更新日期：2026-08-29

## 结论

当前 v17 已有跟随镜头、土狼时间、跳跃缓存、移动平台、检查点和手机触控，基础手感框架合格；但二十关实际重复同一套平台，只通过平台宽度、重力、收集数和少量裂隙增压。四个关卡名循环五次，关卡没有独立空间题、路线选择、新机制、技巧目标或章末高潮，因此仍是技术样例，不是可供用户二次创作的最佳平台跳跃模板。

本轮保留 Phaser Examples 的 MIT 架构参考和平台原创视听资产，只学习成熟游戏的关卡组织、输入减法、可读镜头、失败恢复和辅助设计，不复制角色、关卡、美术、音乐、文本或品牌识别。

## 外部参照锁定

### 主参照：Oddmar

- 来源：[Oddmar App Store](https://apps.apple.com/us/app/oddmar/id1247397901)
- 官方产品信息明确给出 24 个手工关卡、物理解谜与平台挑战、不同环境、武器和护盾，并以移动端完整动作冒险为目标。
- 本模板采用：每关独立几何与机制组合；普通收集路线、技巧路线和风险奖励路线并存；四关一个主题章，每章末有明确追逐或守关场景；角色、交互物和危险物必须从背景中突出。

### 移动端输入参照：Super Mario Run

- 来源：[Nintendo 官方 Super Mario Run 说明](https://www.nintendo.com/us/whatsnew/mobilenews-give-the-super-mario-run-game-a-go-with-daily-unlocks/)、[Nintendo UK 发布说明](https://www.nintendo.com/en-gb/News/2016/September/Super-Mario-Run-coming-to-iPhone-iPad-this-December-1138028.html)
- 可学习：为手机删除不必要输入；同一触控动作通过按压时机和持续时间产生不同结果；角色能力改变路线；关卡同时包含抵达终点、收集与技巧表达。
- 本模板采用：不照搬自动奔跑；保留左右移动，但把右侧主动作收敛为一个大跳跃键，长按控制跳高，空中获得能力后同键触发冲刺；不在手机战斗区放设置或说明面板。

### 精准手感与辅助参照：Celeste

- 来源：[Celeste 官方更新记录](https://www.celestegame.com/changelog.html)
- 官方记录可核对辅助模式、Dash Assist、速度选项、关闭屏幕震动、震动强度和快速重开等设计。
- 本模板采用：保留土狼时间和跳跃缓存；加入快速检查点恢复、可关闭震动、舒缓档的节奏减速与落点辅助；标准和挑战档真实改变危险节奏、平台窗口与检查点，而不是只改重力。

## Refero 界面研究摘要

本轮用五组 iOS 检索检查移动端关卡选择、跳跃教学、触控手势、进度和结算屏，并深读 4 个代表屏幕：

1. LEGO Builder 教学屏：主体占据视觉中心，进度贴边，返回和主动作固定在安全区；大触控目标不与主体争抢。
2. Play 手势教学：只解释一个动作，用触点动画直接演示，确认后不再常驻。
3. Brilliant 步骤反馈：进度、当前状态和错误原因靠近发生位置；未满足条件的动作明确禁用。
4. Brilliant 升级完成：结算只强调一个成果，以短动画强化，不堆叠全部统计。

对应到模板：首次出现长按跳、移动平台、冲刺和机关时各教学一次；战斗中只保留薄 HUD、左右控制和一个主动作；检查点、死亡和通关反馈在主体附近短暂出现；完整技巧统计放到结算页。

## 参照锁与拒绝项

保留：原创云脊题材、9:16 手机优先、跟随镜头、土狼时间、跳跃缓存、检查点、位图角色与平台、桌面键盘和手机触控。

借用：Oddmar 的手工关卡与物理机制递进、Super Mario Run 的移动输入减法与时机表达、Celeste 的快速恢复与辅助选项、Refero 的边缘控件和一次性教学。

拒绝：复制任何参照的具体关卡；二十关复用同一几何；靠缩小平台冒充难度；三枚小按钮挤在底部；镜头展示整个世界导致角色过小；常驻安全落点框；死亡后回到长启动页；背景细节压过角色与落脚面。

## 完整玩法合同

### 单局状态

`任务简报 → 起步段 → 机制段 → 组合段 → 章末挑战 / 信标 → 技巧结算 → 下一关`

死亡不离开关卡：`受击 / 跌落 → 0.35–0.55 秒反馈 → 最近检查点 → 继续`。能量耗尽才进入失败结算。

### 核心循环

1. 镜头提前展示下一处落点和危险方向。
2. 通过左右移动、短按 / 长按跳控制距离和高度。
3. 在空中修正落点，利用弹跳云、移动平台、风场和冲刺节点穿越空间题。
4. 选择安全主路线或包含星核的技巧路线。
5. 点亮检查点，满足关卡条件并抵达终点信标。

### 手感参数合同

- 土狼时间：标准档约 110–130ms；跳跃缓存约 130–160ms。
- 跳跃高度由按住时长控制；松开会削减上升速度，短跳和长跳必须可稳定复现。
- 落地提供压缩、尘粒和短音；起跳提供伸展、尾迹和不同短 / 长跳音高。
- 水平加速、空中修正和落地刹车分开配置；角色不能像冰面持续漂移。
- 高速移动使用分步碰撞，不能穿过薄平台或危险物。
- 镜头使用死区、前视和速度限制；纵向攀升时保持下一落点在画面上半部，下降时优先显示落脚面。

### 交互物与危险语言

| 类型 | 规则 | 视觉 / 声音要求 |
| --- | --- | --- |
| 固定云台 | 稳定落脚 | 厚实边缘、接触阴影、落地粒子 |
| 移动云台 | 按固定轨迹往返 | 轨迹端点先提示，角色随平台位移 |
| 弹跳云 | 自动弹至固定高度 | 压缩后释放，独立高音反馈 |
| 碎云踏板 | 踩中后延时碎裂并重生 | 三阶段裂纹，不突然消失 |
| 风场 | 持续改变水平或垂直速度 | 粒子流向、角色倾斜和边缘箭头共同提示 |
| 冲刺节点 | 恢复一次空中冲刺 | 高亮环、获取音、使用后熄灭 |
| 脉冲门 | 取得钥核或踩开关后开启 | 门和条件使用相同图形符号 |
| 巡游星兽 | 可规避或从上方踩踏 | 移动方向预兆、危险轮廓、踩踏反弹 |

### 目标与星章

- 必做：满足本关条件并抵达信标。
- 星章一：取得关卡主要星核。
- 星章二：在目标时间内完成。
- 星章三：不损失能量或完成该关指定技巧。

星核不能只是终点门票；至少一部分位于可见但需要技巧的副路线。结算只显示本关时间、星核、受击和新获得星章，并提供“下一关”主动作与“重试技巧”次动作。

### HUD、输入和辅助

- 顶部薄 HUD：左侧能量，中间四段进度与检查点，右侧星核和计时；不显示长说明。
- 桌面：A/D 或方向键移动，Space/W/上方向键跳跃；R 快速从检查点重开。
- 手机：左下两个 56–64px 移动触控区，右下一个 72px 主动作；按住跳跃键控制高度，能力解锁后空中再次点击触发冲刺。
- 首次教学用角色附近的短标签和输入动画，动作成功后立即消失。
- 舒缓档增加落点轮廓、降低机关速度、延长土狼时间和检查点密度；挑战档缩短安全窗口并组合危险，但不降低输入精度。
- 启动页可关闭屏幕震动和选择难度；游戏中只允许返回，不常驻设置。

## 放行条件

- 20 个关卡名和 20 套蓝图唯一，五章至少引入 7 类交互物 / 危险。
- 短跳、长跳、土狼时间、跳跃缓存、移动平台携带、碎裂重生、风场、冲刺、门钥和敌对巡逻体可自动验证。
- 手机 390×844 中角色宽度至少占可见战场宽度的 8%，下一落点保持可读；画面不能通过整体缩小展示整关。
- 触控目标不小于 44px，主动作不小于 64px；手机连续按住移动、同时跳跃和松手停止均通过真实输入验收。
- 标准局 60–180 秒；失败检查点恢复不超过 0.55 秒；完整失败、重开、通关、下一关和技巧重试可达。
- 手机和桌面各完成至少 3 局并触发 2 次失败；持续运行无未处理错误，角色和高速机关不穿透。
- 主美确认角色、落脚面、危险、收集物、终点和背景形成稳定六层层级；宣传图不高于局内实际质量。

## 本轮交付结果

- 已以模板级实现替换重复关卡：20 个关卡拥有 20 个唯一名称和 20 套唯一几何蓝图，按五章组织。
- 已落地固定、水平移动、垂直移动、弹跳、碎裂、相位、风场、空中冲刺、门钥和巡逻体 10 类机制；第 17 关较第 1 关收紧安全落脚预览。
- 跳跃支持短按 / 长按、122ms 标准土狼时间和 150ms 输入缓存；冲刺具有独立 260ms 爆发速度窗口；受击后 430ms 从最近检查点恢复。
- 手机采用左下双方向键和右下 76px 跳跃主动作，390×844 下角色可见宽度占战场 9.8%；桌面保持 9:16 舞台并使用右侧任务区。
