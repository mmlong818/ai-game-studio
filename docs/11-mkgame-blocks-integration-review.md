# mkgame-blocks 接入审查

核验日期：2026-08-27  
上游仓库：[MkThingsHQ / mkgame-blocks](https://github.com/MkThingsHQ/mkgame-blocks)  
在线版本：[Super Blocks](https://blocks.mksaas.link/)  
核验提交：`9ca9d7c2e9fd6c23112aeda8044330c403fafd01`

## 结论

这个项目适合新增一个“方块填阵”模板。它与现有“折光堆叠”的俄罗斯方块不是同一种游戏，不能直接替换：俄罗斯方块由上方持续下落并形成时间压力；方块填阵由玩家从三个候选形状中选择，在 8×8 棋盘自由放置并清除完整行列，更接近空间规划和风险管理。

推荐接入方式是“MIT 玩法代码移植 + 平台化重写”。可以复用其独立编写的规则、种子随机、计分和测试思想；名称、界面、位图、音乐、音效、挑战内容和服务器进度全部由平台重新制作。

## 比 mkgame-poly 更适合直接移植的原因

- 核心规则和形状表直接写在 MIT 源代码中，没有依赖从 APK 提取的关卡数据库。
- 经典模式是无限循环，不需要先生产大量手工关卡就能形成完整游戏。
- 每次提供三个拼块，全部使用后才生成下一组；这个节奏天然形成短期规划。
- 放置后同时检测完整横行和竖列，交叉格只清除一次，但按两条线计分。
- 连续消除会提高连击；连续三次未消除会重置连击，难度和奖励关系清楚。
- 种子随机让同一局可复现，适合测试、每日挑战、分享挑战和生成记录。
- 无可放置拼块时立即结束，失败条件可自动验证，不依赖动画或页面状态猜测。

## 值得进入平台规则库的能力

### 玩法内核

- 8×8 棋盘和通用拼块坐标表示；
- 越界和占用检查；
- 横行、竖列及交叉消除；
- 拼块得分、消行得分和连击倍率；
- 三个候选拼块的批次刷新；
- 遍历棋盘判断剩余拼块是否仍有合法落点；
- 可复现的种子随机序列。

### 手机交互

- 从被抓住的具体小格计算拖放锚点，而不是固定使用形状左上角；
- 拖动时显示合法/非法落点预览；
- 同时保留“先选拼块，再点棋盘格”的低精度操作方式；
- 消行期间锁定棋盘输入，避免动画和状态更新互相覆盖；
- 支持触觉反馈、减少动态效果和异常存储降级。

### 自动验证

- 固定种子下的拼块序列可重复；
- 非法放置不能修改原局面；
- 单行、行列交叉、连击和无解结束均有单元测试；
- 浏览器测试覆盖完整消行、得分落盘、刷新恢复、设置、排行榜和错误路由。

## 不能进入本平台的内容

上游 [第三方资产声明](https://github.com/MkThingsHQ/mkgame-blocks/blob/main/THIRD_PARTY_NOTICES.md) 明确指出 `public/game/audio/` 下的音乐和音效来自公开可获取的 Android 应用资产，只供学习和研究。MIT 许可证不授予这些音频的复制、修改或再分发权。

同时不能直接使用：

- TanStarter 派生的浏览器图标和品牌素材；
- “Super Blocks”名称、字标和原界面识别系统；
- 上游音频文件、音频路径或由其加工得到的声音；
- 未单独核验许可证的第三方字体与图标打包产物。

平台需要独立生成封面、棋盘背景、拼块位图图集、消行动画素材、音乐与音效，并在资产清单中记录模型、提示词、哈希和生成时间。

## 对现有“折光堆叠”的影响

这个仓库不能解决俄罗斯方块自身的全部问题，但提供了可直接借鉴的表现方法：

- 拼块应该是有材质、内轮廓和高光的位图单元，而不是一组生硬纯色方块；
- 消除需要保留消除前快照，播放从交点向外扩散的延迟动画、粒子、得分飞字和连击反馈；
- 当前得分应融入游戏画面主层级，帮助玩家在手机竖屏中保持注意力；
- 操作提示应短暂、弱化，不能长期占据游戏区域或遮挡棋盘。

因此，“折光堆叠”继续保留为下落式消行模板；另增“方块填阵”，同时把消除反馈、位图块表现和手机空间利用标准回灌到前者。

## 推荐的原创模板定义

模板暂定名：`block-place` / “果冻填阵”。

- 核心循环：观察三个拼块 → 规划放置顺序 → 填满横行或竖列 → 连续消除提高倍率 → 棋盘无处可放时结束。
- 模式：无限经典、每日固定种子、限步目标、限时连击四种合同能力；首版至少完成经典和每日挑战。
- 难度参数：形状池、最大拼块尺寸、长条出现率、同批相似度、初始占用格、连击重置步数和目标分数。
- 美术方向：软萌、新颖的软胶/果冻/充气材质，每种风格不仅换颜色，还改变块体轮廓、纹理密度、棋盘边框、粒子形状和动效节奏。
- 手机布局：严格 9:16；棋盘占主要视觉面积；三个候选拼块位于拇指可达区；帮助、设置和退出不覆盖棋盘。
- 数据交付：局面种子、得分、连击、模式、版本和每日挑战日期进入平台 SQL；发布后拥有稳定独立网址，并出现在统一游戏列表。

## 接入前的硬性验收

1. 不复制 `public/game/audio/`、上游图标、品牌素材或字标。
2. 归属文件写明实际移植的 MIT 规则结构和核验提交。
3. 固定种子必须生成相同拼块序列；经典模式必须使用新种子。
4. 非法放置不得修改局面；横竖交叉格只删除和记入格子数一次。
5. 三个候选全部使用后才刷新；只要剩余任一拼块可放就不能误判结束。
6. 难度选择必须改变真实形状池和生成概率，不能只改标题。
7. 键盘/点击、拖动、合法预览、刷新恢复和 9:16 小屏路径均需浏览器验证。
8. 位图图集、声音、项目版本、SQL 记录、统一列表和独立发布网址必须通过平台现有交付检查。
