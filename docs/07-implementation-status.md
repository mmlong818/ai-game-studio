## 已执行自动证据

- `npm run typecheck`：通过。
- `npm test`：17 个测试文件、63 项单元与领域端到端测试通过。
- `npm run build`：生产构建通过；截图模块已拆成按需加载，主包约 390KB。
- `npm run test:browsers`：Chromium、Firefox、WebKit 共 42 项真实浏览器流程执行完成；覆盖普通玩家入口、手机版意见面板、开发中补充意见，以及五类 P2 玩法的完整胜利路径。
- 两类完整流程均已覆盖：现有 2048 改造与全新虫虫游戏开发。
- 有限 3D 测试确认三种浏览器均能创建真实 WebGL 上下文。
- 五类 P2 玩法都在 390×844 手机竖屏完成无横向溢出与 44px 主操作检查。
- 稳定发布接口实测返回 200、正确稳定网址及 `X-Studio-Build-Id`，发布指针写入本地持久层。
- 敏感信息扫描未发现真实密钥；交付测试中的 `sk-...` 是故意验证拦截逻辑的假数据。

## 运行凭证状态

当前进程没有 `OPENAI_API_KEY`，所以尚未产生首批真实 AI 图片。这不是静默降级：普通入口和高级工作台都会明确失败、保留旧版本，既不会生成占位图，也不会把其他密钥误当成 OpenAI 密钥。设置密钥后，简化入口会按资源角色生成 AI 位图、绑定场景、创建不可变构建并执行玩法探针。

实体手机与真人双视角复核属于每个游戏版本的发布凭证，不是可由自动测试伪造的平台代码状态。工作台已经把两项设为强制门禁。
