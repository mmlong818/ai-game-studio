# 《掌心工坊》全新黄金游戏实施合同

> 状态：规则、资源合同与候选运行时已完成；原创位图、音效、资源批准和真人试玩待完成。

## 目标

用“有限容器摆放 + 正交邻接协同 + 确定性自动结算”验证一条真正的库外玩法生产链。它不是既有游戏换皮，也不复制参考游戏的名称、角色、美术、音频、数值、物品配方或关卡。

玩家只需一句话提出“做一个把机械零件摆进小盒子、靠相邻关系启动机器的轻松解谜游戏”，系统应自动得到模板、教学、20 关、失败帮助和资源需求；非专业用户只确认整体风格与关键零件方向。

## 已锁定规则

- 所有零件必须完整位于容器内，不能重叠或占用损坏格。
- 只有正交共边算邻接；同一对零件只结算一次。
- 全部零件放完后才能试机，同一布局始终产生相同逐条结算。
- 达到目标分即完成；完整但分散的布局可以失败，因此位置是有意义选择。
- 失败不消耗机会，可移动、旋转、撤销并重试。

## 教学与递进

第一关只要求“查看核心 → 把电池放到相邻格 → 试机并查看结算”三个安全动作。连续失败依次解释缺失协同、高亮一对关系、展示作者解中的一个零件位置。

20 关分五章，每四关一章：点亮核心、读懂协同、容纳双格形状、绕开损坏格、完成七件整机。第 20 关不再引入新规则，只验证综合掌握。
