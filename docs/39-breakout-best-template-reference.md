# 《漆海碎星》最佳模板参照与设计合同

研究日期：2026-08-29

## 设计简报

这是一个面向手机和网页玩家的竖屏打砖块模板。玩家要通过挡板击球角度、连续击破和有限能力管理穿过二十个不同砖阵。它应当容易上手，但不能只靠等待球随机反弹；玩家应能主动控角、用聚光降低瞬时速度、经营连击并决定何时触发爆炸或特殊能力。最大的反对理由是“只有一颗球自动弹、玩家只是左右移动”；玩家第二天应记住的是漆海会随着连击变亮，三连击蓄成十字爆破，而精确回球能够把混乱重新变成可控路线。

## 外部主参照

### 1. Breakout Beyond：连击驱动的强度与主动减速

- Atari 官方页面列出 72 关、特殊砖能力、长连击提升画面强度、牺牲分数换取慢动作的 Focus Mode，以及通关后解锁 Endless Mode。
- 学习范围：连击不只改数字，也改变视听强度；减速是有代价的主动控制；关卡模式与无尽模式共享内核。
- 不复制：横向关卡结构、名称、霓虹视觉、音乐、品牌图形和具体能力外观。

来源：https://atari.com/products/breakout-beyond

### 2. Breakout: Recharged：挑战与能力层

- Atari 官方页面列出 Endless Arcade、50 个挑战关，以及多球、爆炸、导弹等改变局势的能力。
- 学习范围：手工挑战和长局并存；能力必须改变路线判断，而不是只播放特效。
- 不复制：武器名称、关卡、品牌视觉和音频。

来源：https://atari.com/products/breakout-recharged

### 3. Shatter Remastered Deluxe：物理控制、世界与首领节奏

- PikPok 官方页面列出 71 关、10 个世界、9 个首领、四种模式，以及可主动改变球路的吸/推机制、特殊攻击和能力。
- 学习范围：给玩家第二层球路控制；每章改变规则压力；能力条需要积累、激活和可见反馈。
- 不复制：吸/推名称、Shardstorm、首领造型、关卡、美术和音乐。

来源：https://pikpok.com/games/shatter-remastered-deluxe-module-soundtrack/

### 4. Arkanoid Eternal Battle：渐进难度与特殊砖

- Microids 官方页面说明 Neo 模式在经典玩法上加入新关卡、特殊砖、能力和效果，并强调逐关递进难度。
- 学习范围：普通砖、耐久砖与能力砖建立可读层级；关卡变化必须来自规则和布局共同变化。

## 视觉参照锁

- 主体采用 Arc 的深水青黑与高质量水面图像优先原则：深水底、冷白信息、低饱和层次，不让背景争抢球和砖。
- 借用 601 Inc. 的旧金单一强调色，用于爆炸就绪、关键分数和章节数字；不引入多种装饰性色彩。
- 借用 Neon 的近黑表面分层和小面积状态色纪律；不复制纯黑开发者工具外观或绿色品牌色。
- 砖块仍由真实位图提供材质；程序绘制只负责碰撞边界、耐久点、能力标记和高对比规则反馈。

## 本批实装合同

1. 使用子步进碰撞，按撞击面反射，防止高速穿砖和一律纵向反弹。
2. 挡板不同击中位置产生不同回球角度，并限制接近水平的无效球路。
3. 二十种砖阵保持唯一；五章逐步加入耐久砖和三种可识别能力砖。
4. 三连消蓄成一次爆炸；下一次消除自动触发，仅清除自身上下左右十字格。
5. 能力砖提供潮盾、宽挡板和穿透球，效果、剩余量和触发反馈必须可见。
6. 加入聚光能力：消耗能量降低局部时间尺度，同时降低所得分数，形成明确取舍。
7. 连击同时影响倍率、画面强度和环境声强度；失误会中断连击。
8. 提供旅程、120 秒限时和无尽三种模式，模式只在启动页选择。
9. HUD 显示分数、关卡/清场数、机会、连击、爆炸和聚光能量；不覆盖有效砖阵。
10. 结算说明具体成绩与失败原因，不只显示“成功/失败”。

## 验收要求

- 20 关布局签名不重复，五章的速度、耐久率和能力砖数量存在真实差异。
- 固定高速场景连续运行不穿砖、不出现非有限坐标；侧面撞砖会改变水平速度。
- 三连消后炸弹就绪，下一次击破自动清除最多四个正交相邻砖，不清除对角砖。
- 潮盾拦截一次漏球；宽挡板有期限；穿透球有明确剩余次数。
- 聚光开启后时间尺度下降、能量减少且计分折损；关闭后恢复。
- 三种模式共用碰撞与能力内核；限时模式有倒计时，无尽模式清场后继续并提高压力。
- 390×844 中画布尽量满屏，控制区不遮挡挡板、球或最低砖行；桌面无溢出。
