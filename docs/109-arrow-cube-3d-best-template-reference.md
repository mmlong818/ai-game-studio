## 1. 目标与边界

玩家新建通道产出的第二款官方游戏，也是生成通道第一款 3D（three.js）作品。它把《箭头逃脱》的滑出规则搬进三维立方体：单人、离线、全部程序绘制、零位图；不做多人、不做方块旋转或改向、不接入广告或内购。仅供游玩，不进入创作模板或改造映射。

## 3. 规则合同

- 选中方块后沿箭头逐格检查到包围盒外，全空才滑出并消失；被挡则贴着障碍停下并占住新位置，成为新的障碍。
- 全部方块滑出即过关并进入下一关；剩余方块全部无法移动即卡死判负，可重开本关。无生命值、无计时。
- 每关按关号派生种子并用"逐块放置、放置时保证有清空路径"的构造法保证有解；同一种子在任何设备上盘面一致。
- 任何一条直线（X/Y/Z）上不得出现 3 个紧挨着的同向方块（硬约束，回退分支也复检）。
- 每块在轮到被推出时至少有一个朝默认镜头的面外侧为空且不被遮挡。

## 4. 画面、输入与镜头

- 自发光纯色方块（MeshBasicMaterial），每块一种糖果色、相邻不同色，顶面最亮、正面中、侧面略暗三档明度，细线同色相加深描边。
- 箭头画在与方向平行的四个连续面上并指向同一世界方向；箭头指向的出口面与背面纯色。
- 默认左前上方弱透视等轴测视角；可拖动/方向键旋转，"回正"一键复位。空格或"换一块"按屏幕位置循环选块，回车或"推出"确认，点击方块直接选中。
- HUD：关号、剩余块数、步数、无效点击；结算面板含下一关 / 重开本关。

## 5. 关卡与难度

- 100 关，唯一难度维度 blockCount 逐关严格递增（4 → 120）；里程碑关 1/4/5/6/8/10/15/20/30/40/50/60/70/80/90/100。
- 第 1–8 关：2×2×1、3×2×1、3×3×1、3×2×2、单层十字 13 块、3×3×2、双层异形 22 块、3×3×3；第 9–20 关 4×4×3 以内，第 21–50 关 4×4×4 以内，第 51–100 关 5×5×5 以内，形态按"完整长方体 / 异形 / 缺角镂空"循环。
