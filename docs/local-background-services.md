# 本机后台服务

Windows 开发环境可在项目目录执行：

```powershell
./scripts/start-local-background.ps1
```

启动独立隐藏的 Node 进程：前端 4311、API 4312、隔离游戏源 4313。标准输出与错误写入 `data/logs/` 下带时间戳的文件；启动脚本不打印环境配置或密钥。启动后执行 HTTP 就绪检查；已有端口占用时不杀进程、不重复启动，需另外确认占用者确为本项目。

这是本机后台进程，不是 Windows 服务，也没有设置开机启动或崩溃自动拉起。关闭调用终端不应依赖其输出管道维持服务；机器重启、退出登录、进程被终止仍需重新启动。不要宣称该方式保证永久在线。

API 不使用文件监听模式，修改服务端代码后需在没有活动制作任务时安排重启。不要通过整批终止 Node 进程重启；先核对端口和对应 PID。异常后先查看日志和任务持久化状态，不自动重新提交付费任务。
