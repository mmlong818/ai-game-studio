# 《星灵巡格》最佳模板参照合同

更新：2026-08-30

## 设计简报

我们正在设计一款面向手机 9:16 和桌面浏览器的 Star Battle 区域逻辑模板，服务喜欢短局、每日挑战和逐步推理的玩家。玩家需要在不猜答案的前提下，让每行、每列、每个区域都达到规定星数，并保证任意星星不相邻。产品应当安静、清楚、有质感；核心工作是“看懂约束并完成一次可解释推理”，而不是试错或消耗生命。玩家第二天应记得：每次提示都能教会一种真正可复用的推理方法。

保持不变：

- 20 关五章、顺序解锁和三星掌握；
- 手机默认 9:16，桌面和触控均可操作；
- 位图星灵、提示和完成反馈，背景与棋盘不得压缩变形；
- 不复制第三方题库、品牌、美术、声音或宣传素材。

## Refero 界面研究

2026-08-30 通过 Refero 检索 6 组关键词，共审阅 60 个移动端界面；深看 7 个界面：Brilliant 逻辑题与进度、The New Yorker 填字棋盘与提示工具栏、Apple News+ Crossword 的浅色/深色棋盘、玩法说明和题目资料。

Refero 没有提供足够准确的 Star Battle 成品页面，因此这里只把它作为界面层证据，不把相似填字或数独界面当作玩法规则来源。

### 明确拒绝

- 不在棋盘内叠放长说明条或浮动帮助框；
- 不把背景装饰、渐变或大卡片放到棋盘之上；
- 不用六个同权按钮占据主要空间；
- 不用颜色作为区域的唯一边界，粗边界和色块必须同时成立；
- 不在玩家请求提示时直接闪烁答案格；
- 不以“错误次数耗尽”作为标准模式的常规失败条件。

## 玩法合同

### 核心输入

- 默认单击循环：空格 → 星星 → 手动排除 → 空格；符合成熟 Star Battle 的学习成本。
- 工具栏可切换“星星 / 排除”直达模式，方便批量标记；切换模式不改变棋盘。
- 键盘：方向键移动焦点，`Space/Enter` 循环，`S` 放星，`X` 排除，`Z` 撤销，`Y` 重做，`H` 请求提示。
- 自动排除只来自已放星的行、列、区域和八邻域；自动排除不得覆盖手动标记，也不得被计为提示。

### 五章 20 关

| 章节 | 关卡 | 规则 | 推理目标 |
| --- | --- | --- | --- |
| 读懂边界 | 1–4 | 6×6，一星 | 直接排除、单位唯一候选；首关提供可关闭的两步教学 |
| 交叉锁定 | 5–8 | 7×7，一星 | 行/列候选被同一区域锁定，区域候选被同行/列锁定 |
| 复合排除 | 9–12 | 8×8，一星 | 连续两到四步推理；减少视觉引导，不减少可解释性 |
| 双星编队 | 13–16 | 10×10，二星 | 每行、列、区两星；计数完成与剩余候选配额 |
| 星域大师 | 17–20 | 10×10，二星 | 锁定、计数和反证排除组合；仍必须无猜测可解 |

每一题必须：

1. 区域连通；
2. 至少有一个解；
3. 解数严格为 1；
4. 从空盘可由本模板公开的推理规则完成；
5. 推理轨迹与章节目标一致；
6. 20 关的区域签名互不相同。

### 提示合同

提示永远返回“理由 + 影响范围 + 下一动作”，按以下顺序选择当前最基础的一条可执行推理：

1. 星星的同行、同列、同区和八邻域必须排除；
2. 某行、列或区域剩余星数等于剩余候选数，候选全部为星；
3. 某单位已满足星数，其他格全部排除；
4. 某区域的全部候选被限制在同一行或列，可排除该行/列在区域外的候选；
5. 假设某候选为星会使题面无解，因此该格可排除。

提示只执行一次明确推理，不连续代玩；高级关仍可提示，但使用更少额度并影响掌握星章。取消“查冲突 / 排一格 / 亮答案”三个割裂按钮，合并为一个“推理提示”。

## 视觉与声音合同

- 棋盘是绝对第一层级：手机游戏状态下宽度占可用宽度 92–96%，根据 6/7/8/10 格自动调整单格，不拉伸位图。
- 区域采用低饱和不同色相 + 3–5px 连续外边界；自动排除是轻点，手动排除是清晰位图叉号。
- 星灵位图不得被格子裁掉；二星规则中的 10×10 仍需保证星灵可辨，不用缩小文字塞进单格。
- 当前键盘焦点使用细金色内框；提示焦点使用短脉冲光环；错误使用红色对角脉冲，不让整盘闪烁。
- 放星、排除、撤销、推理提示、完成分别使用可区分的短音效；遵守声音总开关。
- 所有关键状态除颜色外至少再有一种形状或线条表达。

## 验收门槛

- 20 个关卡签名唯一；每关 `solutionCount === 1`、区域连通、推理轨迹非空且可完成；
- 第 1、5、9、13、17 关分别触发对应章节的新技巧；
- 13–20 关真实使用 10×10、每单位两星，而不是只改文案；
- 提示返回规则名称和解释，不读取并直接高亮解数组；
- 单击循环、直达标记、撤销、重做、重置、刷新恢复全部实测；
- 手机 390×844 和桌面均无棋盘压缩、遮挡或横向溢出；触点不小于 44×44 CSS px；
- 完成 3 局、制造 2 次直接规则冲突、验证 1 次恢复；控制台无未处理错误；
- 构建、类型检查、模板静态测试、阶段 E 浏览器审计和发布产物哈希一致性全部通过。
