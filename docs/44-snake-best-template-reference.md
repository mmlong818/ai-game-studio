# 《青玉长游》最佳模板参照与重构合同

更新日期：2026-08-30

## 结论

当前 v31 已有 9:16 大棋盘、独立头/直身/转角/尾位图、三档难度、逐帧插值和静态层缓存，画面流畅度与主体资源可以保留。但玩法合同仍未闭合：项目声明支持 `swipe`，运行时却只有键盘和四个屏幕按钮；快速输入只保留一个 `nextDirection`，玩家在一个逻辑步内连续转两个弯时，第二个合法转向可能被当成相反方向丢弃；手机底部还出现实时游戏不应有的“撤销”；20 关只按档位放大棋盘、目标和障碍数，没有固定且可辨认的场型；食物从全部空格随机抽取，没有验证从蛇头出发可达。重构目标是保留经典贪吃蛇的瞬时可读性，同时补齐移动端手感、公平生成、20 个场型、暂停与可复玩统计。

## 外部参照锁定

### 经典规则、速度与迷宫：Snake ’97

- 来源：[Snake ’97 官方站](https://snake97.com/)、[27 项挑战与统计](https://snake97.com/challenges/)。
- 页面公开：同一套时序跨浏览器和移动端保持一致；Snake 1 / Snake 2、12 档速度、7 个迷宫、奖励生物、本地永久高分、27 项挑战；统计包含单局时长、转向次数、险情、食物、距离和长度。
- 本模板采用：四向成长与自体碰撞作为核心、分档速度、固定迷宫/场型、奖励果、本地掌握记录、结算中的长度/转向/险情/时间统计。
- 明确拒绝：复制点阵手机外观、按键造型、1997 声音、品牌和受保护视觉；也不把“怀旧”当成唯一美术方向。

### 跨端输入与控制选择：Snake.io

- 来源：[Snake.io 官方教程](https://snake.io/tutorials.php)、[浏览器版说明](https://snake.io/)。
- 页面公开：移动端提供 Joystick、Arrow、Follow 三种控制；桌面提供鼠标与键盘；控制模式在设置中选择，而不是把所有控件同时压在游戏画面上。
- 本模板采用：手机默认在棋盘上滑动，启动页可切换为四键；桌面保留方向键和 WASD；游戏中只显示当前模式必要的控制，不用无效按钮占据底部。
- 明确拒绝：多人竞技、皮肤商业化、广告增益、付费开局变大、自由角度连续转向和加速击杀；本模板仍是格点单人闯关。

### 可复用状态结构：patorjk/JavaScript-Snake

- 来源：[patorjk/JavaScript-Snake](https://github.com/patorjk/JavaScript-Snake)，MIT。
- 仓库公开：网格、蛇头、当前方向和方向设置均为明确状态；游戏可嵌入指定容器、无外部运行依赖，并保留 AI 驱动接口。
- 本模板采用：网格状态与渲染分离、方向输入队列、确定性关卡蓝图和可测试调试接口；不复制 DOM 界面、美术或历史代码。
- 许可证边界：只借鉴公开结构思想，当前运行时继续使用本项目原创实现和位图资产；如未来复制具体上游代码，必须另行保留 MIT 版权声明。

## 参照锁与拒绝项

保留：项目现有青玉小龙、朱果、庭石、进食/危险/完成位图，浅色当代庭园棋盘，三档难度，9:16 满屏，逐帧插值和静态背景缓存。

借用：Snake ’97 的固定迷宫、速度分档、奖励生物与可复玩统计；Snake.io 的输入模式选择；开源实现的显式网格状态；Refero 的游戏区优先和单目标教学。

拒绝：随机撒石头冒充关卡；只增加速度和目标数字；方向队列吞输入；允许一步内 180° 反转；食物出生在不可达区域；开局未给反应时间；滑动合同没有真实手势；游戏中保留无效“撤销”；四键模式和滑动模式同时占屏；用自动避障或随机续命破坏规则可信度；把多人 Snake.io 机制强塞进单人模板。

## 完整玩法合同

### 核心循环与公平性

1. 蛇每个逻辑步前只消费一个排队方向；队列最多保留两个合法转向，按最后已排队方向拒绝重复和 180° 反转。
2. 开局提供 900ms 观察期；初始蛇身、前进两格和首次转向空间不得放障碍。
3. 食物只能从蛇头在当前障碍图上可达的空格生成，并与蛇头保持最低路径距离；没有合法候选时明确完成或重建，不静默卡死。
4. 普通朱果使长度 +1、计分 +1；中后期按固定节奏出现限时金果，计分 +2、长度仍 +1，以视觉光环和独立反馈区分。
5. 撞墙、撞身体和撞障碍分别记录原因；碰撞只结算一次，结果页展示果实、最长长度、转向、险情、时间和场型。

### 20 关与难度

- 20 关采用 20 个固定名称和场型蓝图，分为五章：开放转向、门廊判断、回环规划、窄路压力、综合长游。
- 每四关形成一次明显增压，不要求每关都更难；压力来自目标、步速、障碍布局、金果时限和身体长度的组合。
- 场型必须保持连通或由可达生成器保证食物不落入隔离区；不得用纯随机位置决定关卡质量。
- 三档难度继续作为启动页选择：轻松允许穿墙且不判自撞；标准使用边界、自撞和场型；挑战提高基础速度、场型密度与目标。关卡增压在三档内部成立。
- 关卡名称锁定为：初游晴庭、双石引路、四隅回身、月门初转、竹影双廊、曲桥借位、回纹花径、方池绕行、折廊追果、双门换向、星石列阵、半月回环、连廊三折、漏窗穿行、镜池窄岸、叠石回廊、九曲藏果、双环合流、庭心风阵、青玉长游。

### 输入与暂停

- 手机默认“滑动”：在棋盘任意位置按下后，主轴位移达到 18 CSS px 即排入一次转向；一次手势只提交一次，斜滑按主轴判断。
- 启动页可改“四键”；四个方向按钮仅在该模式显示。选择在本地保存并用于后续关卡。
- 桌面始终支持方向键和 WASD；P、空格和屏幕暂停键切换暂停。恢复时清空时间累积，避免页面回来立即跳多格。
- 页面隐藏时自动暂停；恢复后由玩家主动继续，不让蛇在后台死亡。

### 反馈与呈现

- 蛇头、身体、转角、尾巴、普通果、金果、障碍、危险、完成至少九类位图角色保持独立职责；程序描边只辅助，不取代位图主体。
- 棋盘是第一焦点；手机滑动模式下不为控制坞预留大块底部空间，HUD 只显示进度、暂停、返回和重开。
- 输入入队立即给轻量方向脉冲，实际跨格继续使用 72–180ms 插值；速度提高时动画时长始终小于逻辑步，不能出现追帧或倒退。
- 危险提示只在蛇头前方一到两格给出，不长时间盖住蛇身；完成效果不遮挡结果数字。
- `prefers-reduced-motion` 下关闭脉冲缩放，但保留位置和颜色之外的形状反馈。

## 自动验收合同

- 20 个关卡名称与场型签名唯一；第 1、5、9、13、17 关形成五档压力差异。
- 在一个逻辑步内输入“上、左”，向右行进的蛇应依次执行上、左，而不是吞掉第二次转向；相反方向不得入队。
- 手机真实滑动可改变方向；同一动作由键盘和四键提交时得到一致的下一个蛇头坐标。
- 普通食物与金果永远不在蛇身和障碍上，且从蛇头可达；连续生成 100 次不出现非法位置。
- 页面隐藏后不再累计逻辑步；暂停、继续、失败、重开和完成均只进入一次正确状态。
- 320×568、390×844、768×1024、1280×720、1440×900 无溢出；390×844 滑动模式棋盘不被方向键压缩。
- 持续运行 60 秒估算刷新不低于 45fps，静态层不会每帧重建，控制台没有未处理错误。
