# 椰风海岛：用户视频参考复刻

日期：2026-09-06。状态：development，可玩首版，不替换虫虫攀枝或纸境折行，不改变现有大厅顺序。

## 已观察的参考特征

用户视频长 80.37 秒，画面显示低多边形海岛卡丁车、八车同场、第三人称跟随、三圈、连续弯道、跨海木桥、金币、道具箱、加速尾焰、小地图、速度与比赛计时。
只能确认视频展示的行为，不能从视频证明对手算法、物理模型、素材许可或引擎实现。当前实现是原创近似，不是源码还原。

## 独立实现

当前发布决策（2026-09-06）：用户确认转为官方仅游玩作品，登记 `stage=live, remixable=false`，大厅第 16 位。下文 development 为早期实现记录；未完成的目标设备/人工审核依旧保留，不因上架而自动通过。

- `fixtures/island-kart/` 自包含静态产物；Three.js 使用项目已安装版本，复制许可证后本地加载。
- 登记表 stage=development；沿平台 fixture 合同注册，但不进入正式大厅，不替换现有游戏。
- 规则与渲染分离：race-core.js / scene.js / app.js。无共享全局 CSS、定时器、存档键或游戏状态。
- 一张约 1088 米的连续闭合赛道：椰林海湾、珊瑚弯道、跨海木桥、暖风村落、冲线海岸。
- 自动加速，左右连续转向，可关闭新手转向辅助；可选减速与能量冲刺。辅助不是自动争冠，收集路线和冲刺仍由玩家选择。
- 三辆车（玩家 + 两个 AI）共用 drive 函数、最高速度、碰撞、能量与道具规则；AI 通过转向输入绕车、靠近收集物，不瞬移。
- 默认三圈竞速，规则模拟约 2 分 7 秒。自由驾驶没有完赛条件；不因到达某个圈数强制结算。
- 金币蓄能，道具箱给护盾或能量；同一物品由首次接触者获得，14 秒后再次出现。
- 暂停/失焦停止规则推进，清空输入；新手帮助在初始界面直接展示。
- 冲线停留与镜头环绕之后显示名次、前三领奖台、最快单圈、金币、个人纪录。难度纪录分别保存。

## 设计知识和审核

依据现有知识库的目标清晰、首次可学会、核心循环、公平性、平台适配硬门槛；新增能力不是一个混合机制卡：

1. continuous-kart-steering：只负责连续车头转向与横向移动。
2. circuit-lap-progress：只负责完整进度、计圈与完赛。
3. energy-speed-burst：只负责能量消耗和短时加速。
4. collect-charge：复用现有收集蓄能机制。

组合玩法 `assisted-circuit-racing` 保持 candidate 状态，不能用自动测试替代真实玩家对“好玩”的审核。

## 验证与边界

规则回归：三圈时长、完整进度、冲刺消耗/过期、左右转向、护栏约束、暂停、无目标自由驾驶、双方规则一致。
浏览器回归：真实键盘和触控、初始帮助、速度与位置变化、冲刺反馈、暂停时钟不变、冲线结算、自由模式、无跨游戏存档键、生产 CSP 下本地资源加载。

当前只有一张赛道和两个模式，没有承诺多赛道战役、联网多人、赛车升级或商业素材级细节。视频中的角色形象不直接复制。后续是否替换虫虫攀枝以用户评审为准。

### 本次验证记录

性能修订：按玩家反馈从八车缩减为三车，静态环境阴影只绘制一次，车辆保留动态接触阴影；仪表以 12.5 Hz 更新，3D 渲染仍跟随浏览器帧率；远处道具仅隐藏渲染、不删除规则，重开复用网格；高 DPI 渲染倍率上限从 1.6 降到 1.25。下列 438–447 次绘制为修订前记录。

修订后相同浏览器回归采样 124 次绘制、97,649 个三角形；另补车辆/镜头帧间插值，使 60 Hz 物理状态之间也能连续呈现。浏览器自动化的帧率不等同于用户嵌入式预览的帧率，仍以实际试玩为准。

- `tests/island-kart.test.ts`：6 项规则测试通过，正常 AI 输入完整三圈约 126.8 秒；不是强制等待。
- `tests/island-kart-browser.test.ts`：生产 CSP 下，1280×720 键盘、390×844 真实触摸事件、短按冲刺、暂停、真实内核快进结算、自由模式超过三圈均通过。
- 浏览器中的木桥截图使用显式位置夹具，结算检查使用规则快进；不将它们冒充全程真人驾驶记录。完整自然三圈由规则测试独立验证。
- 9 项登记表守卫、2 项固定游戏目录测试、54 项设计知识/模板解析/研究回归通过；前后端 TypeScript 检查通过。
- 场景采样约 438–447 次绘制、18 万三角形；不是低端手机帧率保证，仍需目标设备实测。
- 真实截图位于 `output/island-kart/`（本地验收证据，不作为运行时资源）。
- 复现预览命令：`npm run demo:island-kart`。

### 2026-09-06：近景表现与分区预算修订

- 原创圆角车身、保险杠、座椅和尾翼；头盔使用平滑球面。车漆、轮胎、轮毂分别使用不同粗糙度和金属度，降低曝光并调整环境补光。
- 前轮随真实转向状态偏转，轮毂随轮胎滚动，加减速加入小幅俯仰；不增加按键、不改变碰撞或双方驾驶规则，仍为三辆车。
- 静态环境改为 200 米空间分区合批；100 米方案在浏览器回归中超过原有 230 次绘制预算，已弃用，没有提高验收阈值。道路等连续网格尚未进一步切块。
- 同一回归位置本轮采样 199 次绘制、74,857 个三角形，先前为 124 次、97,649 个三角形：这是减少可见几何、增加批次数的权衡，不能据此直接声称帧率提高。
- 7 项规则、1 项桌面/触控浏览器回归、2 项共享规则测试通过，服务端 TypeScript 检查通过。截图在 `output/island-kart/`；目标设备连续帧时间和玩家观感仍待复核。
- 共享要求已进入 `docs/02-quality-and-delivery-v2.md` 和生成提示使用的 `src/shared/game-presentation-policy.ts`。它们是设计/复核要求，不是自动完成的性能认证，也不代表其他存量游戏已改造。
- 本轮保留原有相机时间平滑；建筑局部遮挡淡化尚未实现，不计入完成项。

### 对手可挑战性修订

玩家改为前排起跑；对手不再逐帧重新决策。新手辅助开启时，两名 AI 分别以 93% / 94% 油门巡航，每约 0.36 / 0.39 秒更新输入；关闭辅助时巡航油门为 97%，反应更快。冲刺需至少 75 能量、前方弯曲度合适且经过决策冷却，不再开局马上自动冲刺。玩家仍自动满油门，无新增操作。所有车辆继续共用同一驱动、冲刺速度、能量消耗与碰撞规则；没有按排名瞬移或隐藏追赶加速。以上属于首轮难度校准，不代表已完成真人胜率验证。
