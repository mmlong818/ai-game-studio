# 《朱门华容》最佳模板参照与重构合同

> 2026-09-06：以下 v34 内容是历史基线，不再作为当前重制的放行结论。最新强制标准见《68-klotski-remake-acceptance.md》。当前版本已转向主题题组，第一庭与整关不再是同一概念；旧单棋盘步数及验收条件不能直接用于新版整关评价。

更新日期：2026-08-30

## 结论

重构前的 v32 虽然修过棋子边界、位图完整度和手机 9:16 占屏，玩法层仍不合格：20 关来自同一布局的随机游走，实际最短距离集中在 107–117 个单位步，第一关即接近专家难度；关卡名重复；界面数字与真实最短距离没有共用同一份数据；手机主操作仍是先点棋子再点方向键。现已按本合同完成模板级重构，并以 v34 发布：20 个固定牌局由同一求解器验证，最短距离覆盖 8–120 个单位步；直接拖动、合法方向提示、撤销、重做和玩家路径回放均已落地。重构改变的是可验证的空间规划深度，而不是增加装饰。

- 本模板采用：固定且可复现的关卡开局、明确难度带、唯一目标块、出口第一视觉焦点、可分步查看的解法提示与完整演示。

### 状态模型与求解器：jeantimex/klotski

- 来源：[jeantimex/klotski](https://github.com/jeantimex/klotski)。
- 公开接口把棋盘、棋子形状、位置、目标点和方向限制表示为离散状态，并用相邻状态搜索求解；第一个棋子为目标块。
- 本模板采用相同的可验证状态思想，自行实现本项目的反向广度优先搜索：从所有合法出口状态计算每个布局到出口的最短单位步，离线选择 20 个不同距离带的布局并固化。不会引入运行时依赖，也不复制上游界面或视听资产。

### 商业移动谜题能力：现代 Klotski 应用

- 来源：[klotski - sliding puzzles App Store 页面](https://apps.apple.com/au/app/klotski-sliding-puzzles/id6763393870)。
- 页面公开的产品能力包括：100 个手工谜题、5 档难度、每关经最优解验证、逐步提示、三星评价、撤销、重置、平滑滑动、触感反馈和单手操作。
- 本模板采用：20 个经求解器验证的布局、五章难度、最优步数、一次只揭示下一步的提示、撤销、重置、个人最佳和三星评价；不采用广告换提示或应用的视觉品牌。

保留：4×5 华容道棋盘、2×2 目标块、横块、竖块、四个 1×1 小块、底部中央出口、项目现有可爱机器人与包裹位图。

借用：ThinkFun 的固定挑战与分档、现代 Klotski 应用的最优解验证和逐步提示、Refero 的棋盘优先与单任务教学、离散状态求解器的可验证数据结构。

拒绝：从同一布局随机走几步冒充新关卡；第一关就需要百步；关卡名重复；“参考步数”与真实解不一致；点击棋子后再找方向键作为手机主操作；选中时放大棋子；箭头压在邻接棋子上；自动演示不能暂停；提示直接替玩家完成多步；位图改变棋子逻辑尺寸；完成判定只看动画而不看离散坐标。

## 完整玩法合同

### 核心状态与计步

1. 棋盘固定为 4×5；每个棋子以 `id / w / h / x / y` 表示，逻辑碰撞永远使用整数格。
2. 目标块到达 `(1,3)` 后打开底部两格出口并完成关卡；其他棋子不得离开棋盘。
3. 一步定义为某棋子移动一格。拖过多个空格时按经过的格数计步并逐格写入历史，保证撤销、提示与最优解口径一致。
4. 每次开局都由固定蓝图恢复；局内维护历史栈、重做栈、步数和回放路径，跨会话保存关卡解锁与三星掌握结果。

### 20 关与难度

- 五章各四关，最短解目标带依次约为 `8–24 / 30–48 / 54–72 / 78–96 / 102–120` 个单位步。
- 20 个布局必须来自反向广度优先搜索已覆盖的可达状态；布局签名和最短距离均唯一或成对差异明确，不使用运行时随机打乱。
- 关卡选择显示名称、阶段、任务与星章；开局状态栏显示真实最优步数，未解锁关不能直接进入。
- 名称采用空间策略而非重复的泛化词，例如：初开朱门、双兵让道、横梁移位、回廊换肩、侧门借位、二空接力、长将归边、中心腾挪、折返三隙、双列换位、横刀解扣、门前清障、深庭回旋、四角调兵、错层借道、窄门转轴、长廊逆行、层层设防、水泄不通、横刀立马。

### 直接操作

- 手机和桌面都以直接拖动为主：按下棋子后只沿当前手势主轴移动，松手后按经过的可达整数格逐格提交，并以 210ms ease-out 吸附。
- 点击棋子只选中，不放大；选中状态使用 2–3px 高对比内框和轻微底光，棋子物理尺寸保持不变。
- 若相邻有合法空位，只在空位中心显示低干扰落点，不把箭头压在棋子图案上。非法拖动产生 3–5px 阻尼回弹，不计步、不写历史。
- 键盘支持 Tab / Shift+Tab 切换棋子、方向键移动一格、Z 撤销、Y 重做、H 提示；触控方向键仅作为无障碍备用并默认折叠，不占棋盘底部主要空间。

### 提示、撤销与演示

- 求解器从当前状态给出最短路径；“提示”只高亮目标棋子和下一格，玩家确认或自行移动后才进入下一步。
- 提示不直接移动，只选中最短路径首步所需棋子并指出下一格；玩家移动后才重新计算，避免提示替玩家连续作答。
- 撤销和重做逐格恢复；玩家路径回放从本关开局逐格重演，回放期间锁定冲突输入，完成后恢复操作。
- 锁死不存在于合法华容道状态图中；如果导入或代码错误产生不可达状态，明确报“关卡状态无解”并允许重置，而不是静默卡死。

### 反馈与呈现

- 棋盘占手机可用宽度 90%–96%，出口、目标块、当前选中、合法落点四层信息可在不依赖颜色时区分。
- 位图以 `contain` 方式置于逻辑框，外轮廓由程序统一绘制；横、竖、方和目标块的形状必须一眼可辨，选中不改变大小。
- 移动使用木/陶瓷摩擦短音；撞墙、提示、撤销、出口开启和完成使用不同声纹。连续快速拖动不叠加爆音。
- 完成页突出“个人步数 / 最优步数 / 星章”，主动作是下一关；复盘与重试为次动作，不用大型彩带覆盖棋盘。

## 自动验收合同

- 离线生成脚本输出 20 个合法、可达、唯一布局以及真实最短距离；运行时求解器在浏览器中复核首关与末关距离。
- 每个棋子始终在边界内且互不重叠；任何移动都只沿一个轴并落在整数格。
- 直接拖动一格与键盘移动一格得到相同状态；非法拖动不计步；多格拖动的历史可逐格撤销和重做。
- 从首关与末关的当前状态请求提示，提示的首步必须合法且对应求解器给出的最短路径距离。
- 玩家路径回放结束后恢复可操作状态；完成后保存解锁与星章，重开恢复固定蓝图。
- 390×844 下棋盘不被方向键、提示条或底部面板压缩；目标块、出口和空位均可辨认；1280×720 下鼠标拖动和键盘完整可用。

## 放行条件

- 20 个固定关卡跨越五个真实最短距离带，第一章可在数十秒内理解，最终章保留经典深度。
- 逐步提示、撤销、重做、玩家路径回放和解锁保存都使用同一离散状态口径，不再出现伪最优数字。
- 真实触发指针拖动、撤销、重做、提示和路径回放；首关与末关求解距离一致，浏览器无未处理错误。
- 构建自动验收、阶段 D 华容道专项验收和主美复核全部通过后，才替换稳定网址。
