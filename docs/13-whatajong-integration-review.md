## 页面公开的玩法事实

- README 将其描述为 roguelike Mahjong Solitaire。
- 一张牌只有在未被上层牌覆盖，并且横向至少一侧开放时才是自由牌。
- 两张自由牌图案匹配时可以消除；没有可用对子或牌面清空时结束当前局。
- `setupTiles` 先模拟成对移除，再按相反顺序把牌对放回，从结构上保证初始牌局存在完整解法。
- Run 由多个 round 组成，包含 game、reward、shop、gameOver 和 end 等阶段；局间可扩展牌组和升级材料。

## 本平台重制范围

- 原创 9:16 手机竖屏游戏《月港雀旅》。
- 独立实现牌层遮挡、左右开放、对子匹配、提示、洗牌、撤销和无对子判定。
- 独立实现可解牌局生成器，不复制上游响应式地图。
- 三段式旅程和局间遗物选择，保留肉鸽决策感但不复制上游商店、卡池和材料体系。
- 由 GPT Image 2 生成原创宣传封面和九种陶瓷灵牌位图；声音由本平台程序化合成。

## 不接入内容

- 上游 `assets/tiles`、`backgrounds`、`textures`、字体、音乐和声音文件。
- Whatajong 名称、Logo、首页构图和现有文案。
- 上游具体响应式牌阵、商品池、24 级成长表、角色能力和数值。
- 任何第三方站点数据、埋点或桌面端持久化实现。

## 成功标准

1. 用户能清楚区分自由牌和被阻挡牌，并可通过单击完成一对消除。
2. 每局初始牌阵由反向放置算法保证可解；洗牌也重新建立可解顺序。
3. 完成一局后出现三选一遗物，选择后进入下一航段；最终完成整次旅程。
4. 画布保持 9:16，不被帮助框覆盖，触控和键盘均可操作。
5. 主体牌面使用真实位图图集，且所有上游与重制边界随构建归档。
