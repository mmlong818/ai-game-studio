# 游戏设计知识库(提炼版)

来源:创作者提供的五份参考资料(游戏机制、101 游戏机制、益智游戏设计清单、策略游戏设计清单、TCG 框架设计提示词),2026-08-28 提炼。本文件是**平台生成专业设计合同的知识基准**:`src/shared/design-knowledge.ts` 中的机器可用词表与准则由此维护,两边必须同步修订。

## 1. 设计支柱(所有生成的设计合同必须体现)

1. **明确目标**:每一关、每一局的目标必须一句话可理解;战略决策由清晰传达的目标引导。
2. **有意义的选择**:玩家的决定要产生可感知的后果;避免"只有一种可行打法"。
3. **渐进复杂度(串联信息论)**:机制分步引入,信息最小碎片化;先教会再加压,避免开局压垮新手。
4. **平衡的难度曲线**:逐级递增、无断崖;同档内允许题面/路线/阵型变化而非全部数值上涨(与平台二十关合同一致)。
5. **即时反馈**:每个关键操作、成功、失败都有可区分的视听反馈;反馈解释"发生了什么、为什么"。
6. **损失厌恶与风险回报**:用可失去的进度/资源制造张力,用敢于冒险的奖励制造兴奋;不滥用惩罚。
7. **可重玩性**:随机种子、多解法、可选挑战、分数追逐至少占其一。
8. **视觉清晰优先**:主体(玩家/棋盘/目标)是第一视觉层级;交互元素必须可辨识,美术不得牺牲规则可读性。
9. **主题一致性**:题材、机制、美术、声音、文案互相印证,不做"皮肤换色"。
10. **无障碍**:触控目标、对比度、色盲可辨、可调难度是设计要求而非附加项。

## 2. 专业机制词表(供 LLM 解析与设计合同使用)

从 101+22 条机制中甄别,剔除游戏化营销条目(病毒式传播、约定登录等),保留对小游戏设计真实有用的词汇,按类分组:

- **进程类**:关卡推进、经验/等级、任务与挑战、里程碑成就、解锁内容、翻身战(逆转机会)
- **规则类**:回合制、倒计时、连击/连消、组合技、冷却、资源管理、建设放置、区域控制、健康/生命系统、风险回报抉择、随机机遇、隐藏信息/战争迷雾
- **反馈类**:得分、进度条、即时视听反馈、奖励计划(应急/响应/增强)、巨额奖励时刻
- **认知类**:解谜推理、空间推理、模式识别、路径规划、记忆、反应时间、策略规划
- **动机类**(用于目标玩家画像):成就感、发现探索欲、掌控感、收集欲、紧迫感、幸运感、自我表现
- **玩家人格参照**:探险家(发现)、成就达人(完成度)、社交爱好者(比较分享)、杀手(竞争压制)——设计合同的目标玩家描述应指明主要服务哪类。

## 3. 品类设计清单(生成对应玩法的设计合同时逐项自检)

### 益智/解谜类(适用:拼图、华容道、迷宫、区域逻辑、多格拼块、方块填阵、2048)
- 核心机制一句话可说清(匹配/排序/空间推理/路径);易学难精。
- 规则与约束显式:合法操作、步数/时间/资源限制、例外规则。
- 提示系统分层(轻推→直接指导),可跳过难关但有代价;防挫败是设计义务。
- 评分透明:效率/速度/最少步数的加成规则玩家可见。
- 多解或多难度档;避免同类型谜题机械重复。
- 常见错误:一次塞太多机制、指示不清、难度突刺、视觉杂乱淹没拼块。

### 策略/长局类(适用:麻将肉鸽、太空射击波次、未来的塔防/卡牌/经营)
- 资源系统:来源、消耗、稀缺权衡;流入流出平衡防滚雪球。
- 战略分层:经济×战斗×成长互相牵制,短期战术 vs 长期规划的抉择点。
- 多胜利路径且各有独特挑战;动态目标随局势演变。
- 单位/元素角色分明、有克制关系;无单一主导打法。
- AI 对手行为要能适应玩家策略,避免固定套路被背板。
- 常见错误:复杂度压垮新手、平衡失控产生唯一解、微观管理过度、反馈循环缺失。

### 动作/街机类(适用:俄罗斯方块、打砖块、贪吃蛇、平台跳跃)
- 手感即内容:输入即时响应、失败原因永远可读("我知道我为什么死")。
- 压力曲线用速度/密度/波次分档收紧;高潮与喘息交替。
- 连击/连锁作为技巧上限,基础操作作为下限。

## 4. LLM 设计生成范式(源自 TCG 框架提示词,平台后续设计合同生成遵循)

1. **输入模板化**:主题/目标受众/复杂度(入门/中级/专家)/特色机制/参考作品——缺项应用**智能默认值**(由主题推断卡组/属性,由受众推断复杂度,由复杂度决定系统深度)。
2. **复杂度分级输出**:入门=单一资源+基础规则;中级=双资源+中等战斗;专家=多资源+深度系统——生成物的系统数量随复杂度伸缩,不做一刀切。
3. **固定输出骨架**:概述与世界观→核心机制→系统设计→资源→对抗/结算→流程(准备/回合/阶段/特殊时机)→胜利条件(主/替代/平局)→扩展性。骨架保证专业完备,内容随输入变化。
4. **一致性检查**:所有元素在主题与机制上互相印证;排除项要给理由(方案-收益-代价-排除理由)。
