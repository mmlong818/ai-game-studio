# 阶段 A 修复交付：发布质量底座

日期：2026-08-27

## 本批已经落地

1. 玩法合同升级到展示协议 v5，正式保存目标画幅、镜头模式和输入方式。
2. 十三类生成模板统一使用 `idle / playing / paused / stage-complete / won / lost / restarting` 状态协议；《星梦对决》也接入相同协议。
3. 每次构建都会启动真实 Chrome/Edge，在 320×568、390×844、768×1024、1280×720、1440×900 五档画幅检查：
   - 横向溢出、首屏开局、游戏主体尺寸和 44px 触控目标；
   - 开局前非法输入、开始、合法动作、胜利结算和重开；
   - 控制台错误、未处理异常、资源请求失败、HTTP 错误和图片解码；
   - 5 张开局截图、1 张游玩截图、1 张结算截图；
   - `_studio/BROWSER_QUALITY_REPORT.json` 原始验收记录。
4. 版本表新增自动验收状态、证据摘要、主美复核状态、复核说明和时间。
5. 发布闸门改为双门槛：自动验收与主美复核必须同时通过；失败版本不能切换稳定网址。
6. 制作页新增“版本与发布”：最近 5 个版本直接显示，更早版本折叠；可查看在线版本、自动验收、主美结论，并把稳定网址切回任一历史合格版本。
7. 修复“重新构建后游戏从大厅消失”的数据状态错误：已有在线版本的项目继续保持已发布状态。
8. 《星梦对决》已从固定目录迁移到正常的不可变版本流程：
   - v1 已快照保留，原版本网址仍可访问；
   - v2 通过五档浏览器验收和主美复核后切换到稳定网址；
   - 稳定网址不变：`http://127.0.0.1:4312/play/star-dream-duel/`。
