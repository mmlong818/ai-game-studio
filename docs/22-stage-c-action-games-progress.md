# 阶段 C：实时动作游戏修复进度

> 历史进度快照。阶段 C 已在 2026-08-27 完成，最终代码、真实浏览器证据、版本号与回滚验证见 [阶段 C 完成报告](./25-stage-c-action-games-completion.md)。

## 已完成并进入新版本

### 《星环突围》v10

- 玩家飞船从 64×82 提升至 80×104，真实画面中不再是小点。
- 手机输入改为按下后持续拖动，并使用指针捕获；悬停不会误移动飞船。
- 前 15 秒使用较慢生成曲线，敌人入场前有 620–920ms 顶部预警线。
- 未击落的敌机只中断连击，不再直接扣血；只有真实碰撞造成伤害。
- 加入 850ms 受击无敌、受击闪烁、击破爆散、连击状态和危险提示。
- 色块样式去掉大面积粗黑边，改为深海青面板、珊瑚危险色和薄描边。
- 真实浏览器持续运行 18 秒仍处于 `playing`，无控制台错误；飞船、敌机和预警线均清楚可见。

### 《云脊跃迁》v9

- 9:16 画幅启用 1.35 倍纵向跟随镜头，不再一次展示完整 1280 高场景。
- 角色宽度提高到 56px，镜头内显示宽度约为游戏区域的 10.5%。
- 加入 105ms 土狼时间、130ms 跳跃缓冲和 180ms 落地压缩反馈。
- 镜头分别平滑跟随横向与纵向位置，下一落点在真实画面中可读。
- 真实浏览器开局、运行与资源加载无错误。

### 《青玉长游》v24

- 蛇身使用连续圆角路径连接，头、交替身体和尾部使用不同方向位图。
- 三档难度同时改变网格、目标、边界、自碰撞、速度和障碍数量。
- 标准加入 3 个障碍，挑战加入 9 个障碍；失败明确显示边界、自身或庭院障碍原因。
- 进行中切换难度改为 2.5 秒内二次确认，避免误触清空当前进度。

### 《漆海碎星》v24

- 保留五关独立背景、形状、行列、球速与护盾率。
- 独立砖块、挡板、球和撞击特效位图已替代源图集直读。
- 关卡完成期间使用 `stage-complete` 锁定输入，随后进入下一关。

## 当前发布结论

四个版本都通过 17/17 自动与真实浏览器检查，但暂不发布到稳定网址。阶段 C 的剩余验收仍包括《星环突围》掉落与十分钟持续输入、《云脊跃迁》四段关卡和安全落脚预览、《青玉长游》转角资产及完整完成演出、《漆海碎星》五组受损砖块层级。未完成这些项前，不把“能运行”伪装成阶段完成。
