# 牧野小火车：木制铁路玩具沙盒

## 研究与范围

2026-09-06 使用真实浏览器打开 [Choo-Choo World](https://choochooworld.com/?DATA=/0/D)，进入 Start Building，阅读五步引导并打开轨道工具、启动列车。页面标题明确为 wooden train track builder；观察到直路长短、左右弯、特殊轨道、升降、颜色、撤销/删除、编辑/观赏、播放/暂停、返回车站与相机旋转缩放。它不是竞速游戏。本实现是玩法启发的独立原型，不是官方版本或逐像素复制。

## 设计

- 对象：想立即玩起来的非专业用户。唯一主要动作是点轨道部件，自动沿末端位置与切线连接。
- 核心循环：接轨 → 查看真实连接 → 发车观察 → 撤销或延伸 → 保存自己的世界。
- 默认只差一个左弯即可闭环；不要求强制完成目标。无关卡、无输赢、无计时压力。
- 直路/左右弯/坡道/木桥/隧道七类部件；颜色只改变后续部件。
- 三节列车沿同一路径等距采样；开线路末端停车折返，闭环持续运行。
- 平面交叠拒绝，高架足够净空允许交叉；高度、地图与 96 段上限可解释。撤销/重做不破坏路径。
- 存档只用 meadow-railway.world.v1；首次帮助只用 meadow-railway.help.v1，不碰其他游戏。
- 轨道按钮悬停、键盘聚焦和触控按下时显示实际候选路径；合法浅黄色、非法珊瑚红，地下无效路径投影到地面以保持可见。点击仍直接放置，不增加二次确认。
- 闭环后的轨道按钮折叠，明确提供“拆开末段，继续搭建”；已保存闭环刷新后也能拆开，拆除进入撤销历史。
- 新线路提供 18 段桥隧旅行线：包含上下坡、一段高架木桥、两段拱廊，已逐段验证合法、闭环和可保存恢复。

## 视觉方向与技术

规则内核与表现分离，60Hz 固定更新与距离插值。Three.js 依赖本地化；静态地形与轨道按材质和 24 单位空间块合并；静态阴影仅搭建后刷新；DPR 上限 1.5，烟雾 18 个实例。编辑重建释放上一组轨道几何，不重复生成材质。游戏入口可独立静态运行。

## 当前边界

第一版实现单条连续轨道，没有道岔/多车调度、交叉路口自动优先权、自由搬动物件、昼夜变化、在线分享或多尺寸轨道。隧道是可穿过的短拱廊，不是完整地形洞穴。存档明确手动保存，不冒充云同步。摄像机默认轨道总览，旋转/缩放与跟车可用。

第二轮表现改造：车头采用圆角驾驶室、分层锅炉、金属箍、车灯和烟囱，三车共 14 组带辐条轮组，机车两侧连杆按真实行驶距离同步转动；车厢装木料与收获物。车站改斜屋顶、木板站台、窗框、灯柱和围栏。林木成簇分布，池塘与花丛只放在离当前轨道足够远的空地，新增轨道优先，避免装饰压住通路。默认构图转向站台正面；手机全景和近景分别设定距离，雾的起点随观察距离调整，不让拉远的线路消失。

人工美术审查、真实目标手机帧率、Firefox 与 WebKit 仍待验证；不可据无头浏览器性能宣称 60FPS。

## 原型验收记录（2026-09-06）

第二轮：10 项确定性规则测试、1 项生产 CSP 浏览器场景、2 项平台目录测试、9 项登记守卫通过，前后端类型检查通过。浏览器覆盖 1366×768 与 390×844；8 次撤销/重做后 GPU 几何数保持 226。新增反向行驶中闭环的负距离回绕、拆开已加载闭环、删轨后列车位置和插值同步归一测试。当前默认环线采样 188 次绘制 / 66600 三角形，仍在 220 次绘制的回归预算内；不声称造型增加没有成本。测试截图在 `output/meadow-railway/`，代码哈希和待验证项目记录于游戏内 `_studio/QUALITY_REPORT.json`。

首版历史采样为正常发车 23 秒，平均帧时间 6.109ms、P95 6.2ms、100 draw calls / 41044 三角形；它不能代表第二轮增加造型后的性能。最新采样以 `_studio/QUALITY_REPORT.json` 为准，所有无头测试均不代表用户预览或目标手机达标。

第二轮最终采样：18 段桥隧旅行线正常发车 40 秒、完整运行一圈，没有快进；本机 RTX 5080 / Windows HeadlessChrome 152、1264×569、DPR 1，平均 6.060ms、P95 6.2ms，采样点 230 draw calls / 96692 三角形 / 240 几何。采样前段另一个隔离浏览器同时运行回归；该数字不是纯净设备基准。较大示例比默认环线增加绘制成本，默认 <220 的回归断言不意味着任何布局都 <220；96 段极限布局继续待测。

本地启动命令：`npm run demo:meadow-railway`。该脚本使用独立端口，运行时不依赖其他游戏目录。
