# 低高度窗口与真实点击验收

2026-09-07

## 诊断

上轮脚本展开成功但坐标点击失败有两方面原因：桌面制作台设定 min-height: 640px，超过 569px 的实际可视高度；浏览器自动化 click 命令又未可靠地滚动屏幕外目标。事件证据显示点击 y=578 命中 HTML，而不是入口 SUMMARY。不能据此误判审核接口或 React 事件故障。

## 修复

移除桌面制作台固定最小高度，按 100dvh 布局，右侧 workbench-stream 负责内容滚动。860px 以下原有 height:auto / min-height:100dvh 的手机纵向布局保持不变。没有用强制展开或额外点击监听掩盖问题。

## 验收规则

- 必须同时覆盖宽度与高度：低高度桌面至少测试 1280×480，以及约 1264×569；手机覆盖 390×844。
- 先滚动目标进入可见区域，再用真实指针点击；读取展开状态，并验证键盘 Enter。
- 不以 element.click() 脚本结果替代坐标点击验收，也不以工具返回 Done 作为成功依据。
- 对异常记录实际命中的元素与坐标，区分布局故障、工具滚动限制和应用事件故障。

## 本次结果

569px 桌面真实点击命中 SUMMARY，外层详情与审核历史均展开，键盘 Enter 正常收起。480px 桌面制作台高度等于实际窗口高度，历史点击展开；390px 手机可点击收起。类型检查通过，未写入审核、发布或制作请求。证据截图位于本地 audit-2026-09-07/screenshots/review-click-480.png。
