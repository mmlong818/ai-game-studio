# 最佳模板游戏持续改造计划

更新日期：2026-08-30

## 基准与边界

- 《月港雀旅》v39 是当前冻结的质量基准，不再进入后续批次修改。
- 其他模板必须先完成外部参照研究，再允许修改规则和界面。
- 学习的是完整设计方法：核心循环、输入、信息层、难度、关卡、反馈、结算、复玩和移动端适配；不复制名称、品牌、受保护的视觉识别、音乐或素材。
- 每次改造生成新的不可变版本；旧版本和稳定网址可回退。

## 单款模板的强制流程

1. **参照锁定**：一个同玩法主参照、一个表现参照、一个移动端或结算参照；记录来源、日期和可学习边界。
2. **设计拆解**：形成玩法状态图、规则参数、20 关变化、输入与镜头合同、视觉与声音反馈表。
3. **实现**：修改模板运行时和公共生成合同，不只修复某一个既有项目产物。
4. **规则验证**：合法动作、非法动作、胜负、恢复、随机/可解性、难度差异和长局稳定性。
5. **真实试玩**：手机和桌面各完成核心流程；游戏设计师与游戏爱好者审核手感，主美审核主体和反馈，产品经理审核发布与回滚。
6. **发布**：自动质量闸门和人工主美均通过后，才把稳定网址切到新版本。

## 最佳模板放行条件

- 首次进入 3 秒内看懂主体、目标和主要操作。
- 核心规则与成熟参照的关键能力一致，任何有意差异都有产品理由。
- 至少 20 关或等价的 20 个可识别进度目标，五档压力真实变化。
- 手机 390×844 尽量满屏，游戏中不显示会遮挡主体的设置和长期说明。
- 核心资源、UI、声音和反馈来自同一艺术方向；宣传图不高于局内实际质量。
- 自动完成至少 3 局胜利和 2 局失败；实时游戏还要验证持续输入、帧节奏和暂停恢复。
- 发布版本拥有独立网址、版本记录、来源说明、质量报告和稳定网址回滚能力。
