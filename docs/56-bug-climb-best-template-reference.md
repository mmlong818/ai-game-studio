# 虫虫攀枝：参照、边界与固化说明

更新时间：2026-09-03

## 1. 定位与来源

虫虫攀枝是官方原创的单局制短程游戏：Q 版小瓢虫在巨大树干的三条树纹之间高速攀爬，也可以在有限范围内上下走位；玩家躲避树瘤和琥珀树脂，用头部吸收露珠积蓄冲刺能量，收集金色种子，并在倒计时内连续通过三个树层抵达树冠。

它最初经平台实验通道（`template = generated`）由模型生成，并在 2026-08-31 至 09-01 间迭代到 v13（腿部独立骨架、无腿主体位图等改进）。2026-09-03 官方把 v13 的不可变构建产物固化为固定游戏 `fixtures/bug-climb/`，登记为 `official-games/bug-climb.ts`，与其他官方游戏同等对待：随源码分发、服务启动自动注册、创作页可作为“多道攀爬”模板改造。

产物内 `_studio/` 保留了当时的设计文档、美术方向、声音方向、规则保真记录、开源归属与 gpt-image-2 位图溯源（`DYNAMIC_ART.json`）。

## 2. 可追溯参照

核心玩法参照为“竖屏三车道闪避”品类（代表作 Subway Surfers）：玩家固定在画面下方、三条路线始终可判断、障碍提前进入视野、横向输入立即完成、速度提高但不牺牲公平性。只借鉴玩法比例、镜头组织和反馈节奏，不复制任何角色、场景、商标、配色或美术资产。详见产物内 `_studio/TEMPLATE_REFERENCE.md`。

## 3. 采用与不采用

采用：三条等宽路线与固定正交顶视图；横向换树纹即时生效，并允许有限上下走位；每个生成批次至少一条安全通路；露珠先补充能量，玩家按住冲刺后才加速并能撞碎树脂；金色种子只提供分数与长期收集；三个树层连续递进并分别倒计时。

障碍直接绘制在树干上，不使用半透明路线底框或边界箭头。树瘤、树脂消失，树脂被撞碎，以及障碍从角色身边通过时都不触发屏幕震动；受击仍保留粒子、文字、声音和体力反馈。界面统一把原先含义模糊的“贴边险避”改为“惊险躲过”。

不采用：无尽模式与货币化循环；角色技能树；任何参照游戏的具体内容。

## 4. 验收方式

- 固定游戏注册时写入的验收合同：安全路线可判断；左右换树纹与有限上下走位有效；露珠吸收、冲刺加速、树脂破坏、普通碰撞和倒计时结算各自独立；键盘、触控按钮和四向滑动可以完成一局。
- 自动回归检查锁定：树瘤与树脂不绘制半透明底框；障碍消失、撞碎和惊险躲过不触发画面震动；游戏内不再出现“贴边险避”。
- 产物内 `_studio/BROWSER_QUALITY_REPORT.json` 是固化时的历史检查记录；后续改动以当前源码测试和最新真实浏览器检查为准，不能把旧报告当作新版本证据。
- 创作侧模板“多道攀爬”（`lane-climb`）从登记表派生，其课程顺序调整为：判断安全道 → 换树纹或上下走位 → 头部吸收露珠 → 主动冲刺破树脂 → 完成三个阶段。模板不再把“拾取露珠”错误描述成“立即加速”。

## 5. 后续

再次修改这款游戏时，以 `fixtures/bug-climb/` 为源码，更新登记文件、本文档和回归测试，并同步当前服务实际读取的构建产物。只有美术资源变化时才更新美术溯源。

1.1 起，`fixtures/<kind>/` 是只读来源，服务会把它复制为 `data/artifacts-v1.1/<versionId>/` 的版本化副本并补齐工程清单。副本清单记录了来源指纹（文件路径、大小、修改时间），源目录一旦改动，下次访问会自动重新复制并重建清单，因此本地开发仍然是“改了源目录、刷新即生效”，发布出去的副本保持完整可追溯。当前三个树层主要依靠速度和生成频率递进，阶段内容差异仍有限；在扩展出更多障碍组合或阶段规则前，不把它描述为 20 关长线模板。
