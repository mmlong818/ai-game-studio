# PostgreSQL 发布并发验证

2026-09-07

## 目的与执行

验证复核与发布同时发生时，发布使用的是锁等待结束后的审核结论，而非请求开始时的旧结论。

执行 `npm run test:publication-postgres`。显式集成测试入口不纳入常规 `*.test.ts`，需要本机 PostgreSQL 和建 schema 权限；读取本地环境文件，不输出连接凭据，不调用模型。

## 验证场景

1. 创建唯一隔离 schema，用真实仓储建立模拟项目、旧公开版本和新审核通过版本。
2. 独立连接启动新版本复核，将结论改为不通过，暂缓事务提交。
3. 第二个连接请求发布新版本，通过 PostgreSQL 锁等待信息确认阻塞者就是复核连接。
4. 释放复核事务，断言发布被拒绝，旧公开版本不变，审核历史序号和结论完整。
5. 清理仅本轮新建的 schema，并查询系统目录断言清理完成。

## 边界

真实 PostgreSQL 独立连接测试通过。使用实际数据库事务和行锁，不是 SQLite 时序模拟，但仍是单进程中的两个独立连接池，不代表多实例压力测试、进程崩溃恢复或整个浏览器制作链路均已验证。

本次不修改真实游戏、发布记录或审核结论，不触发付费生成，不改变“发布后重新复核失败不会自动下线”的现行策略。
