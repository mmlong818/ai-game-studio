## 1. 目标与边界

这是玩家新建通道（参考复刻 → 核心玩法分析 → 生成 → 真人试玩修订）产出的第一款官方游戏，用来证明"玩家可以新建并玩到自己的游戏"这条主路径能交付可上架的作品。它只做单人、离线、程序绘制的箭头滑出解谜；不做多人、不做箭头移动/旋转、不接入广告或内购。仅供游玩，不进入创作模板或改造映射。

## 3. 规则合同

- 点击箭头时沿其朝向逐格检查到棋盘边缘，全空才滑出并清空所占格子；滑出动画整条箭头沿自身折线前进，头部出口后再直线飞出（额外 步数+2 格），时长 max(120ms, (轨迹点数−1)×70ms)。
- 被挡的箭头原地不动、红闪 320 ms 后永久变深色并扣 1 颗心；与上一次被挡的箭头相同时不重复扣心；任意一次成功滑出后清空该记录。
- 全部箭头离场即过关；4 颗心扣光或第 2 关起倒计时归零即中断，可从开局快照重试（心回满、连胜清零）。
- 每关盘面由固定种子生成并经剥离验证可解；时限 = 向上取整到 5 的倍数(max(4×箭头数, 120)) 秒，第 1 关不计时。
- 计分只有连胜：过关 +1，重试清零；里程碑关（10、20）有独立结算档位。

## 4. 输入、镜头与信息层

- 桌面：鼠标点击箭头；方向键 / WASD 移动光标、回车发射；`+`/`−` 缩放。手机：单指点按发射，拖动超过阈值进入平移，双指缩放。
- 画幅 9:16 优先，桌面居中；棋盘按 `max(4, min((可用宽−28)/W, (可用高−28)/H))` 自适应格边长，缩放 1–3 倍并钳制平移。
- HUD：关号与关卡标签、倒计时（第 1 关留空，≤60 s 警示）、4 颗心、连胜火焰、设置；结算浮层含重玩 / 下一关。

## 5. 关卡与难度

- 20 关有限战役，难度维度 boardWidth / boardHeight / arrowCount / timeLimitSeconds 全部来自真实关卡配置。
- 前 20 关按原作关卡表规律：L1 15×20/45（不计时）、L2 17×23/55、L3 20×20/65（正方形）、L4 24×31/85（椭圆点阵）、L5–L9 逐关微增、L10 大关 35×49/158、L11–L19 25～26×32～34、L20 大关 36×50/166。
- 生成器：长箭头 / 中箭头 / 短箭头 / 合并 / 延伸 / 封顶 / 填满 各阶段，每步以"反复剥离可直接离场箭头"验证全盘可解。剥离探针与真实点击自动通关证据见 docs/106（2026-09-14）。

## 6. 美术与声音

- 抽象线条风：细线圆角折线箭头、20 色索引、点阵棋盘、纸面 HUD（visualStyle `line-art`），程序绘制；资源说明见 `fixtures/arrow-escape/_studio/ART_PROVENANCE.md`。
- 声音：Web Audio 合成——滑出上行音阶（900 ms 内连发升级）、被挡低频双击、过关分层胜利音；首次交互后启动。
