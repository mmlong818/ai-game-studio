# 纸境 · 立体书迷宫（暂名）— 3D 示范游戏概念锁定

状态：概念图已由产品负责人确认方向（2026-09-03）。本目录是后续开发的视觉与玩法基准；改动这里的任何决定都要先更新本文件。

## 1. 定位

平台的官方 3D 示范游戏，同时作为可改造的玩法模板。目标是“审美和玩法都在线”：不是能跑的 Demo，而是放进大厅后能代表平台水准的作品。

视觉规则：

- 几何：Three.js 程序化低多边形，平面着色；每块纸面有 1 到 2 像素的浅色纸边。禁止照片平铺、禁止把位图立牌当成 3D 物体。
- 材质：AI 生成的纸纹、印花、贴纸作为贴图；每章一套主色板（4 到 5 色 + 1 个强调色）。
- 光影：单一主光加半球环境光，柔和阴影，轻雾，ACES 调色；移轴景深只在高性能档开启。
- 镜头：固定等角三分之一俯视；玩家只能把整本书按 90 度转动，不能自由旋转镜头。
- 动效：翻页开场、纸片折起/展开、角色纸偶式的轻微弹跳、纸屑粒子。所有动效有 reduced-motion 回退。

## 3. 玩法基准

核心点子：**转一转，路就出现了。** 桥、台阶、隐藏星星只在特定角度接得上或看得见。

- 一关 1 到 3 分钟。通关条件：抵达出口门。评价：三颗折纸星（可选收集），通关时间不作为失败条件。
- 检查点旗：失败（坠落 / 触碰纸片危险）回到最近检查点，不整局重来。
- 操作：滑动（或 Q/E）把书转 90 度；点击地面走过去（或方向键）；一个跳跃键。手机只需两种手势加一个按钮。
- 20 关分 4 章，每章引入一种新元素，且与上一章叠加：
  1. 晨光草甸：旋转看路、断桥在另一角度接上。
  2. 海岸灯塔：会动的纸浪与纸鸟障碍，需要等时机。
  3. 灯笼夜市：机关开合桥与压板，按顺序触发。
  4. 雪原天文台：限时门与综合运用。
- 每一关都必须由自动探针在“正确角度序列”下完成一次，并证明至少一颗星只在非默认角度下可见。

## 4. 不复制什么

机制来自“空间旋转谜题”这一成熟品类，参照只用于确定可验证的结构（在 docs/ 下另立参照合同，格式同 docs/51）。不使用任何商业游戏的角色、关卡、美术、音乐或界面识别；不出现文字化的品牌联想。
