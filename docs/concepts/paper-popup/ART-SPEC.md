# 纸境 · 立体书迷宫 — 可执行美术规格

对照物：同目录 01–04 概念图。所有数值以网格单位（1 格 = 1.0）为基准。本规格分两层：**基础层**（书页、纸台、光、镜头、桌面）与**构件层**（章节装饰）。基础层由主工作区直接实现；构件层按本规格派发。规则内核与 20 关数据不得改动。

## 1. 镜头与取景

- 固定等角三分之一俯视，方向向量固定为 `(0.5, 0.82, 0.866)` 归一化；不允许自由旋转。
- 取景以**整本书**（含书页外沿）为拟合对象，而不是网格：竖屏书页占画面高度 ≥ 60%，桌面保持在竖屏上下各 ≤ 20%；桌面版书页占画面宽度 ≥ 70%。
- 书页外沿到网格边缘的留白：竖屏 0.9 格，桌面 1.2 格。留白只用来放构件，不放可走格。
- 目标点放在网格几何中心、高度为最高纸台的 40%；不要因为 HUD 把书往下压。

## 2. 纸台（每个可走格）

| 部件 | 规格 |
| --- | --- |
| 主体 | `1.0 × h × 1.0` 无缝盒；侧面两色：受光面 `side`，背光面 `sideShade`，明度差 ≥ 18%（HSL L 值） |
| 顶纸 | 厚 0.12，四边各外扩 0.03（1.06 × 1.06），颜色取章节 `top`，两格棋盘交替明度差 6% |
| 层线 | 每 1 层高度一条 0.04 厚、颜色 `sideShade` 再深 8% 的横线，读出“很多张纸叠起来” |
| 纸边 | 顶纸外沿双层描边：内层 `edge` 不透明度 1.0，外层缩放 1.02 不透明度 0.55；主体竖边单层 0.7 |
| 纸纹 | `paper-grain.png` 每格 UV 随机偏移，重复 1.5；顶纸另叠章节印花时不透明度 ≤ 0.25 |
| 阴影 | 所有纸台投射与接收阴影 |

## 3. 光与色

- 主光：方向光，位置 `(-6, 12, 5) × 场景半径/6`，强度 3.4；阴影 PCFSoft，radius 3，normalBias 0.02。
- 环境：半球光强度 0.55（原 0.85 太亮，压平了纸的立体感）；`hemiSky` 略偏冷，`hemiGround` 比 `desk` 深 25%。
- 曝光：ACES，草甸 1.0、海岸 1.0、夜市 1.45、雪原 0.98。
- 雾：颜色等于 `sky`，near = 相机距离 × 2.2，far = × 4.5（只柔化最远端）。
- 四章主色直接取 03-chapter-palettes：
  - 草甸：纸 `#f3e9d2`，顶 `#8fae7a / #86a571`，侧 `#d9c39a / #b99e73`，强调万寿菊 `#e8b23a`，次 `#d97f66`
  - 海岸：纸 `#f1e8d4`，顶 `#9cc9c0 / #90bdb4`，侧 `#e3d3b3 / #c4b18a`，强调珊瑚 `#d97d64`，次墨蓝 `#27406a`
  - 夜市：纸 `#4a4577`，顶 `#8d6aa6 / #83609b`，侧 `#6a4d84 / #4f3a63`，强调琥珀 `#f4a44a`，次 `#bd6684`；场景亮度靠灯笼、门、摊位窗的自发光与 ≤ 6 个点光
  - 雪原：纸 `#f4f8fb`，顶 `#f7fafc / #ecf2f7`，侧 `#cfdde9 / #aec2d3`，强调黄铜 `#c9a45c`，次 `#7f9cba`

## 4. 书与桌面

- 书页厚 0.3，书封厚 0.14，书脊居中；书页颜色 `page`，纹理 `paper-grain.png` 重复 3。
- 桌面不用照片纹理：纯色 `desk` + 纸纹低对比（不透明度 ≤ 0.35）+ 屏幕空间暗角（四角 -12% 亮度）。
- 书页右下角一枚章节圆形印花贴纸，直径 1.5 格，只此一处使用位图。

## 5. 构件层（章节装饰，派发部分）

硬指标：
- 密度：网格外圈环带（书页留白）每 1.5 格长度至少 1 个构件；网格四角各至少 1 组“主构件”（树/灯笼杆/灯塔/天文台等）。
- 层次：每个构件至少 2 层纸片（前后错位 0.05–0.1），松树 3 层以上，颜色由深到浅逐层提亮 6–10%。
- 尺寸：主构件高度 1.2–2.2 格，次构件 0.3–0.7 格；所有构件基座不进入可走格与星格 0.6 格半径内。
- 章节专属：草甸（多层松、纸花簇、灌木、纸云）、海岸（灯塔、纸船、三层纸浪、海鸟）、夜市（灯笼串、摊位、屋影带窗、月牙）、雪原（雪松、雪堆、天文台圆顶、望远镜、星点）。
- 背景：远端两排纸山/屋影保留，但颜色改为章节 `backdrop` 的三档，最远一排再叠 15% 的 `sky` 提亮。
- 低性能档：构件数量 × 0.4，但四角主构件必须保留。

## 6. 验收方式

- 三处固定截图（手机第 1 关、手机第 12 关、桌面第 20 关）与概念图并排对照，由产品负责人确认。
- 自动：竖屏书页占画面高度 ≥ 60%（在浏览器测试里用投影包围盒计算并断言）；`auditPopupBlueprints()` 与关卡签名不变；三浏览器测试通过。
