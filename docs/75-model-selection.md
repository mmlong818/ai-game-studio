# 远端模型发现与选择

- 输入完整 Key 后防抖 600ms，由本地后端调用官方 GET /v1/models。Key 不进入 URL、日志、浏览器存储或游戏产物；查询不修改生效配置。
- 仅展示与当前请求参数兼容的通用 GPT-5 及后续数字版本文本型号、GPT Image 型号；排除音频、嵌入、Realtime 等不同用途。模型列表不提供完整能力信息，不能仅靠 created 宣称某个型号支持所有接口。
- 推荐按数字版本降序；支持 Astra、Sol、Terra、Luna 命名后缀，同一代旗舰（Astra/Sol）优先于均衡（Terra）与轻量（Luna），稳定别名优先于日期快照，再按 created 排列。所有选择必须实际出现在该 Key 的远端列表，不用本地默认值冒充发现结果。
- 可以立即点击保存，由后端先发现再采用推荐型号；也可以等待列表后选择型号再保存。换 Key、迟到响应、查询错误均不得污染旧设置。
- 保存后设计、代码与图片请求读取所选型号；生成溯源记录不再只允许固定的图像型号。列表可见不代表额度、组织认证或具体任务一定可调用。
- 沿用原有安全策略：界面保存到当前服务会话，重启后不保留；服务器文件或环境变量 Key 仍为回退来源。没有新增明文密钥落盘。
- 测试覆盖版本排序、用途过滤、直接保存、手动选择、失败原子性、空列表和换 Key 请求竞态；消费者既有回归另行验证。

接口依据：[OpenAI 官方 List models](https://developers.openai.com/api/reference/resources/models/methods/list)。推荐排序是平台策略，不是官方提供的“最新模型”标记。

本地直接启动且使用 .env.local 中的代理时，使用 node --env-file=.env.local --use-env-proxy --import tsx src/server/index.ts，确保 fetch 启用已配置代理。2026-09-06 修复命名后缀误过滤后，实际只读查询确认推荐 gpt-6-astra / gpt-image-2，文本列表同时包含 gpt-5.6-sol、gpt-5.6-terra、gpt-5.6-luna。可用性与推荐随账号和时间变化，不写死到界面。此验证只读取列表，没有进行付费文本生成调用。
